# 💧 Consumo de Água

Sistema desenvolvido em **Python** para classificar o perfil de consumo de água de diferentes tipos de imóveis e emitir alertas educativos aos moradores.

## 🎯 Objetivo

O programa solicita o **tipo de imóvel** e o **consumo mensal de água em m³**, classificando o consumo de acordo com as regras estabelecidas pela companhia de saneamento.

### 📊 Classificações

* 🏢 **Comercial:** informa que a tarifa comercial foi aplicada.
* 🏠 **Apartamento com consumo inferior a 10 m³:** consumo econômico.
* 🏠 **Apartamento ou casa com consumo de até 25 m³:** consumo moderado.
* ⚠️ **Demais situações:** consumo excessivo, com orientação para economia de água e verificação de possíveis vazamentos.

## ▶️ Como executar

1. Certifique-se de ter o **Python** instalado em seu computador.
2. Baixe ou clone este repositório.
3. Abra o arquivo `app.py` em um ambiente de desenvolvimento Python.
4. Execute o programa.
5. Ao iniciar o programa:

   * 🏠 Informe o **tipo de imóvel**: `comercial`, `casa` ou `apartamento`.
   * 💧 Informe o **consumo mensal de água em m³**.
6. O programa analisará as informações fornecidas e exibirá a classificação correspondente ao perfil de consumo.
